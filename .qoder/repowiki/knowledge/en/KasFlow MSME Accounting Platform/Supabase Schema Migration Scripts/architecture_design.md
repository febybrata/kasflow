Flat directory of idempotent, single-purpose PostgreSQL migration files under `supabase-migrations/`, each named with a `YYYY-MM-DD_` prefix so Supabase's built-in migrator can apply them in chronological order. Every file is self-contained: it adds columns/constraints/indexes via `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`, backfills existing rows (e.g. marking pre-existing statements as `auto_approved`, seeding new default accounts per-company from `business_profiles`), and documents intent through header comments plus `COMMENT ON COLUMN`. There is no orchestration script — Supabase CLI (`supabase db push`) consumes the directory directly. Dependency direction is strictly forward-only; later migrations (e.g. `2026-06-20_fix_dividen_account.sql`) correct earlier seed data rather than redefining schemas.
