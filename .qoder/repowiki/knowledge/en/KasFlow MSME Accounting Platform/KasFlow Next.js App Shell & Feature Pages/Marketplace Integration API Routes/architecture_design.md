Two sibling integration sub-packages share the same Next.js App Router layout: `integrations/tiktok/` and `integrations/shopee/`, each mirroring a uniform endpoint surface (`auth`, `approve`, `callback`, `sync`) plus platform-specific resource routes (TikTok adds `shops`, `orders`, `statements`, `mapping`, etc.). A top-level `callback/route.ts` handles the shared TikTok OAuth redirect flow. All handlers talk to Supabase directly via the service-role REST client or SDK, persisting connections into `marketplace_connections` keyed by `company_id` + `platform` + `shop_id`. Cross-cutting concerns — environment-driven credentials (`TIKTOK_APP_KEY/SECRET`, `SHOPEE_*`, `SUPABASE_*`), HMAC signature generation, and error-to-redirect conventions — are duplicated per handler rather than centralized in a shared library, so each route is self-contained.
