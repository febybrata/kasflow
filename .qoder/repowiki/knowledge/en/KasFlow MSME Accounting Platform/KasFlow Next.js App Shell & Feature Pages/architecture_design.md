The `app/` directory is the Next.js App Router root. `layout.tsx` sets a single runtime contract for every child page: `dynamic = 'force-dynamic'` so all pages are 100% client-rendered (browser APIs + Supabase client), wrapped by `<Providers>` then `<AppShell>` which supplies navigation and layout chrome. Each top-level subdirectory (`accounting`, `integrations`, `marketplace`, `master-data`, `onboarding`, `reports`, `settings`, `tax`, `transactions`, `utilities`) maps to a route segment whose `page.tsx` is a `'use client'` component consuming the shared Zustand store (`use-kasflow-store`) and Recharts via `ClientOnlyChart`. The sibling `api/` folder declares Route Handlers (Next.js 14+) for OAuth callbacks and sync endpoints used by those same client pages; there is no server-side data fetching — clients call these handlers directly. The root `page.tsx` is the dashboard entry point linking into each feature area.
