Two parallel artifact trees: `docs/` holds the living Product Requirements Document (`PRD.md`, v3.0) plus supporting summaries (implementation plan, Shopee API notes, keep-alive strategy), while `reff/` stores external reference material — TikTok Shop API docs (authorization, orders, finance), a Puppeteer scraping guide, and the authoritative Supabase migration DDL for the marketplace extension (`supabase-marketplace-schema.sql`). The schema file is the single source of truth for the five new tables (`marketplace_connections`, `marketplace_account_mapping`, `marketplace_orders`, `marketplace_order_items`, `marketplace_statements`) and documents the agreed statement-based sync approach (one daily statement → up to three journal entries, idempotent via `kasflow_transaction_id`). Dependency direction is one-way: code consumes these artifacts; nothing in this module imports application code.
