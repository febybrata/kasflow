Single-leaf module split into four responsibilities:
- `client.ts` — thin factory wrapping `@supabase/ssr`'s `createBrowserClient` with implicit auth flow; also exports `isSupabaseConfigured` for env checks.
- `bootstrap.ts` — one-shot `bootstrapCompanyForUser` that creates a `business_profiles` row, a `users` row, then seeds default accounts/categories/cash_accounts/tax_settings/accounting_periods from `@/lib/accounting`, plus an audit log entry.
- `company-service.ts` — the main data-access surface: per-entity async functions (get/add/update/soft-delete/restore) over `business_profiles`, `customers`, `suppliers`, `transactions`, `journal_entries`, `accounts`, `account_categories`, `cash_accounts`, `tax_settings`, `accounting_periods`, `audit_logs`; uses `snakeToCamel`/`camelToSnake` helpers to bridge Postgres snake_case columns and application camelCase types; integrates with `@/lib/accounting` to auto-generate journal entries on transaction write and closing entries on period close; all writes are accompanied by `addAuditLog` calls.
- `use-company-sync.ts` — React hook that subscribes to a single Supabase Realtime channel (`kasflow-sync-${companyId}`), performs an initial parallel fetch of critical tables, then re-fetches changed tables on `postgres_changes` events and patches the global `useKasFlowStore` in-place; debounces audit-log refetches.
- `database.types.ts` — hand-maintained `Database` type mirroring the TikTok-sync tables (`marketplace_connections`, `marketplace_account_mapping`, `marketplace_orders`, `marketplace_statements`, `marketplace_sync_logs`) as a stopgap until `supabase gen types typescript` is available.

Dependency direction: `bootstrap.ts` → `client.ts`; `company-service.ts` → `client.ts` + `@/lib/accounting` + `@/lib/types`; `use-company-sync.ts` → `client.ts` + `@/components/auth-provider` + `@/store/use-kasflow-store` + `@/lib/accounting`; `database.types.ts` is consumed only by the marketplace sync layer outside this scope. No file imports another sibling except through `client.ts`.
